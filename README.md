# Dokkan Multi-tenant Web App

Dokkan is a multi-tenant web application built to provide isolated environments for multiple tenants within a single application instance.

## Key Features

- **Multi-tenancy Support**: Efficiently manage multiple tenants with data isolation.
- **Scalable Architecture**: Designed to handle growth in users and data.
- **Tenant Management**: Tools for managing individual tenant accounts and configurations.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm (bundled with Node) or yarn/pnpm
- Docker Desktop (optional — required to run the full stack with containers)

This repository contains two main projects: the `Backend` (Node + TypeScript) and the `Frontend` (Vite + React). Follow each subproject's `README.md` for project-specific setup steps.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MohamedEMonem/Dokkan.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Dokkan
   ```
